📞

{% if lang == 'te' %}1. కాలింగ్ & డయలర్{% else %}1. Calling & Phone App{% endif %}

{% if lang == 'te' %} ఆకుపచ్చ ఫోన్ గుర్తుపై నొక్కి నంబర్ డయల్ చేయండి లేదా కాంటాక్ట్స్ నుండి కాల్ చేయండి. కాల్ వచ్చినప్పుడు సమాధానం ఇవ్వడానికి ఆకుపచ్చ బటన్‌ను పైకి స్వైప్ చేయండి. {% else %} Open the Phone app (green handset icon). Tap the keypad to dial numbers, or swipe recent callers. To answer an incoming call, swipe up or tap the green receiver. {% endif %}

👥

{% if lang == 'te' %}2. కాంటాక్ట్స్ సేవ్ చేయడం{% else %}2. Contacts & Favorites{% endif %}

{% if lang == 'te' %} కాంటాక్ట్స్ యాప్‌లో (+) చిహ్నాన్ని నొక్కి పేరు, మొబైల్ నంబర్ నమోదు చేసి 'సేవ్' నొక్కండి. మీ ముఖ్యమైన కుటుంబ సభ్యుల నంబర్లను 'Favorites' లో చేర్చండి. {% else %} Open Contacts and tap (+) to add a family member or friend. Enter their name and phone number, then tap Save. Mark frequent contacts as Favorites for one-tap dialing. {% endif %}

💬

{% if lang == 'te' %}3. మెసేజింగ్ & వాట్సాప్{% else %}3. Messaging & WhatsApp{% endif %}

{% if lang == 'te' %} వాట్సాప్‌లో వాయిస్ మెసేజ్ రికార్డ్ చేయడానికి మైక్ గుర్తును నొక్కి పట్టుకోండి. అపరిచిత వ్యక్తుల నుండి వచ్చే లింకులను ఎప్పుడూ క్లిక్ చేయవద్దు. {% else %} Use WhatsApp to exchange messages, photos, and voice notes. Press and hold the microphone icon to send an audio message without having to type. Never tap unknown forwarded links. {% endif %}

📶

{% if lang == 'te' %}4. వై-ఫై & మొబైల్ డేటా{% else %}4. Wi-Fi & Mobile Internet{% endif %}

{% if lang == 'te' %} స్క్రీన్ పైనుండి కిందికి స్వైప్ చేసి వై-ఫై గుర్తును రెండు సెకన్లు నొక్కండి. మీ ఇంటి వై-ఫైని ఎంచుకుని పాస్‌వర్డ్ ఇవ్వండి. బయట అపరిచిత ఉచిత వై-ఫై వాడవద్దు. {% else %} Swipe down from the top edge of your screen. Tap and hold the Wi-Fi icon to select your home network and enter your router password. Avoid using public open Wi-Fi for banking. {% endif %}

⚙

{% if lang == 'te' %}5. శబ్దం & స్క్రీన్ సెట్టింగ్స్{% else %}5. Volume & Display Settings{% endif %}

{% if lang == 'te' %} ఫోన్ పక్కన ఉన్న వాల్యూమ్ బటన్లతో రింగ్‌టోన్ పెంచుకోండి. సెట్టింగ్స్‌లో 'Display' లోకి వెళ్లి 'Screen Timeout' ను 2 నిమిషాలకు మార్చండి, తద్వారా స్క్రీన్ వెంటనే ఆగిపోదు. {% else %} Use side buttons to adjust ringer and in-call volume. In Settings > Display, increase the Screen Timeout to 2 or 5 minutes so your screen does not turn off too quickly while reading. {% endif %}

👁

{% if lang == 'te' %}6. సులభంగా చదివే సౌలభ్యం{% else %}6. Accessibility & Large Text{% endif %}

{% if lang == 'te' %} సెట్టింగ్స్ > Accessibility లోకి వెళ్లి 'Font Size' మరియు 'Display Size' ను 'Large' చేయండి. అక్షరాలు స్పష్టంగా కనిపించడానికి 'High Contrast Text' ఆన్ చేయండి. {% else %} Go to Settings > Accessibility > Text and Display. Increase the Font Size and Display Size slider. Turn on High-Contrast Text for easier reading without eye strain. {% endif %}
