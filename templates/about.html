{% if lang == 'te' %}మా లక్ష్యం మరియు దృక్పథం{% else %}Our Mission & Vision{% endif %}

{% if lang == 'te' %} భారతదేశంలో వేగంగా విస్తరిస్తున్న డిజిటల్ సేవలు (UPI, వాట్సాప్, ప్రభుత్వ పోర్టల్స్) మరియు స్మార్ట్‌ఫోన్ సాంకేతికతను సీనియర్ సిటిజన్లు స్వతంత్రంగా, భయం లేకుండా ఉపయోగించేలా శిక్షణ ఇవ్వడం డిజిటల్ సాథీ ప్రధాన ఉద్దేశం. {% else %} The primary mission of DigitalSaathi is to bridge the digital divide for elderly citizens. With rapid digitalization across banking, utility payments, and family communication, seniors often face anxiety and vulnerability to cybercrime. We provide patient, accessible education, safety tutorials, and personal volunteer support. {% endif %}

{% if lang == 'te' %}సమస్య సవాలు{% else %}The Challenge{% endif %}

{% if lang == 'te' %} చిన్న అక్షరాలు, కష్టమైన ఇంగ్లీష్ భాష, మరియు నిరంతరం మారుతున్న యాప్ ఇంటర్‌ఫేస్‌ల వల్ల సీనియర్లు ఇతరులపై ఆధారపడుతున్నారు. సైబర్ నేరగాళ్లు వీరి అమాయకత్వాన్ని ఆసరాగా చేసుకుని OTP మరియు నకిలీ బిల్లుల ద్వారా మోసగిస్తున్నారు. {% else %} Elderly citizens frequently struggle with small fonts, unfamiliar smartphone interfaces, and fast-paced digital apps. Cyber fraudsters increasingly target seniors through electricity bill threats, remote-access screen apps, and deceptive payment links. {% endif %}

{% if lang == 'te' %}పరిష్కారం{% else %}Our Approach{% endif %}

{% if lang == 'te' %} డిజిటల్ సాథీ ద్వారా స్థానిక భాషలో (తెలుగు & ఇంగ్లీష్), పెద్ద అక్షరాలతో, ఓపికగా నేర్పించే వాలంటీర్ నెట్‌వర్క్‌ను అందుబాటులోకి తెచ్చాము. దీని ద్వారా సీనియర్లు ధైర్యంగా సాంకేతికతను వాడగలుగుతారు. {% else %} DigitalSaathi offers high-contrast bilingual guides with large fonts, real-world scam scenario quizzes, step-by-step smartphone tutorials, and a dedicated 1-to-1 volunteer support request system. {% endif %}
