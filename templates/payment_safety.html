💰
Golden Safety Rule

{% if lang == 'te' %} డబ్బులు అందుకోవడానికి ఎప్పుడూ UPI పిన్ లేదా OTP అవసరం లేదు! {% else %} Receiving Money NEVER Requires Entering Your UPI PIN or OTP! {% endif %}

{% if lang == 'te' %} ఎవరైనా మీకు పెన్షన్, లాటరీ లేదా రీఫండ్ పంపుతున్నామని చెప్పి PIN నొక్కమంటే అది 100% సైబర్ మోసం. పిన్ ఎంటర్ చేస్తే మీ ఖాతా నుండి డబ్బు కట్ అవుతుంది. {% else %} If someone claims they are sending you money and tells you to scan a QR code or enter your 4/6-digit UPI PIN, it is guaranteed cyber fraud. Entering your PIN always sends money out of your account. {% endif %}

🔒

{% if lang == 'te' %}UPI పిన్ రహస్యం{% else %}Keep Your UPI PIN Secret{% endif %}

{% if lang == 'te' %} మీ 4 లేదా 6 అంకెల UPI పిన్‌ను ఎవరితోనూ పంచుకోవద్దు. బ్యాంక్ అధికారులు లేదా కస్టమర్ కేర్ ప్రతినిధులు కూడా పిన్ అడగరు. {% else %} Your UPI PIN is like your ATM PIN. Never write it down or share it over phone calls, even if the caller claims to be your bank manager. {% endif %}

📲

{% if lang == 'te' %}OTP ఎవరికీ చెప్పవద్దు{% else %}Never Share OTP with Anyone{% endif %}

{% if lang == 'te' %} OTP (వన్ టైమ్ పాస్‌వర్డ్) అనేది మీ బ్యాంక్ లాకర్ తాళం లాంటిది. 'KYC అప్‌డేట్' లేదా 'బిల్లు చెల్లింపు' పేరుతో వచ్చే ఫోన్ కాల్స్‌లో OTP చెప్పకండి. {% else %} One-Time Passwords (OTP) authorize transactions. Real bank employees will never ask you for an OTP. Never read out OTPs to any caller. {% endif %}

📷

{% if lang == 'te' %}QR కోడ్ స్కాన్ భద్రత{% else %}QR Code Scam Awareness{% endif %}

{% if lang == 'te' %} షాపుల్లో వస్తువులు కొని బిల్లు చెల్లించడానికి మాత్రమే QR కోడ్ స్కాన్ చేయాలి. డబ్బులు స్వీకరించడానికి QR కోడ్ స్కాన్ చేయవద్దు. {% else %} QR codes are only meant to pay out money at merchant counters. Scanning a QR code sent over WhatsApp will debit your account, never credit it. {% endif %}

🔔

{% if lang == 'te' %}SMS అలర్ట్స్ పరిశీలన{% else %}Always Read Bank SMS Alerts{% endif %}

{% if lang == 'te' %} ప్రతి లావాదేవీ తర్వాత బ్యాంక్ నుండి వచ్చే SMS ను శ్రద్ధగా చదవండి. 'Debited' అంటే డబ్బు తగ్గింది, 'Credited' అంటే డబ్బు చేరింది. {% else %} After every payment, check your SMS. If you see the word 'Debited', money was deducted. If you see an unexpected debit, contact your bank immediately. {% endif %}

{% if lang == 'te' %}1930 కి వెంటనే కాల్ చేయండి{% else %}Dial 1930 Immediately{% endif %}

{% if lang == 'te' %} మొదటి 2-3 గంటలలో (గోల్డెన్ అవర్) 1930 జాతీయ సైబర్ హెల్ప్‌లైన్‌కు ఫిర్యాదు చేస్తే బ్యాంక్ ఆ డబ్బును నిలిపివేస్తుంది. {% else %} Reporting to the 1930 National Cyber Helpline within the golden hour enables authorities to freeze the stolen funds immediately. {% endif %}

2

{% if lang == 'te' %}బ్యాంక్ ఖాతా లేదా కార్డు బ్లాక్ చేయండి{% else %}Block Your Card / Account{% endif %}

{% if lang == 'te' %} మీ బ్యాంక్ టోల్-ఫ్రీ నంబర్‌కు కాల్ చేసి మీ ATM కార్డు మరియు నెట్ బ్యాంకింగ్‌ను తాత్కాలికంగా బ్లాక్ చేయమని కోరండి. {% else %} Call your bank's 24x7 customer support toll-free line to immediately block your debit card and suspend internet banking access. {% endif %}

3

{% if lang == 'te' %}ఆన్‌లైన్‌లో ఫిర్యాదు నమోదు చేయండి{% else %}Report on Cyber Portal{% endif %}
